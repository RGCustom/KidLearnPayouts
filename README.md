# KidLearnPayouts («Мотиватор»)

Домашнее веб-приложение, которое превращает учёбу и помощь по дому в понятную и честную игру с деньгами: за сделанное ребёнок получает баллы-рубли, за провалы — небольшие штрафы, а раз в неделю накопленное выплачивается.
Работает у вас дома, в Docker (Unraid и любой другой хост), данные хранятся только у вас.

## В чём суть

Родители заранее договариваются с ребёнком о тарифах: сколько стоит домашка, посуда, мусор, оценка в школе, контрольная. Дальше всё просто:

1. Сделал дело или получил оценку — родитель делает запись в пару нажатий.
2. Сумма копируется в «накоплено к выплате», ребёнок в любой момент видит её на главной странице.
3. В пятницу накопленное выплачивается (целиком или частично), остаток и штрафы переносятся дальше.

Просмотр открыт всем, кто в домашней сети, а записи, выплаты и правка тарифов защищены паролем — так ребёнок видит свой результат, но не может его «поправить».

## Чем это полезно для мотивации

- **Понятные правила вместо уговоров.** Тарифы известны заранее и не меняются в одностороннем порядке. Не нужно напоминать и спорить: «сделал — получил».
- **Быстрая обратная связь.** Награда видна сразу, а не «когда-нибудь потом». Ребёнок наглядно видит связь между действием и результатом.
- **Видимый прогресс.** Крупная сумма на главной, шкала до выплаты вне очереди и график по неделям превращают учёбу в игру с понятной целью.
- **Усилия, а не только оценки.** Платятся и ежедневные привычки (домашка вовремя, дела по дому), и результат (оценки, контрольные), поэтому есть за что получить награду даже в неудачную неделю.
- **Мягкие последствия.** Штрафы за низкие оценки небольшие и прозрачные: ребёнок учится отвечать за результат без скандалов и наказаний.
- **Первый опыт обращения с деньгами.** Накопить, отложить часть, потребовать выплату вне очереди — азы финансовой грамотности на реальном примере.
- **Меньше конфликтов в семье.** Тема учёбы и дел переходит из эмоций в договорённости. Родителям не надо «пилить», ребёнку — оправдываться.
- **Статистика для разговора.** Средний балл, распределение оценок, итоги по категориям и неделям помогают спокойно обсудить, что получается, а что нет.

> Приложение — инструмент для договорённости, а не замена общения. Лучше всего работает, когда правила обсуждаются вместе с ребёнком, а тарифы пересматриваются по мере взросления.

## Возможности

- **Обзор** — сумма к выплате, прогресс до выплаты вне очереди, быстрые записи, график по неделям.
- **Записи** — категории дел (по тарифам), оценки и контрольные, свои записи с суммой ±, отмена последней записи.
- **Выплаты** — полная или частичная (остаток переносится), с проверкой актуальной суммы.
- **История и статистика** — все записи и выплаты, итоги, разбивка по категориям, распределение оценок, средний балл.
- **Тарифы** — категории дел (добавить, переименовать, сумма, «раз в день», штрафные с минусом, удаление), суммы за оценки и контрольные, лимит выплаты вне очереди, имя ученика.
- **Договор** — текст семейного договора собирается автоматически из тарифов (один или два родителя), печать и сохранение в PDF.
- **На экран «Домой»** — иконки и manifest для iPhone/Android, работает как приложение.

## Установка на Unraid

1. Дождитесь зелёной галочки в **Actions** (образ собирается автоматически при каждом коммите в `main`).
2. В терминале Unraid скачайте шаблон:
   ```
   wget -O /boot/config/plugins/dockerMan/templates-user/my-KidLearnPayouts.xml \
     https://raw.githubusercontent.com/RGCustom/KidLearnPayouts/main/kidlearnpayouts.xml
   ```
3. **Docker → Add Container →** в выпадающем списке шаблонов выберите **KidLearnPayouts**.
   Задайте пароль (`ADMIN_PASSWORD`), проверьте часовой пояс (`TZ`) и порт → **Apply**.
4. Откройте `http://IP-сервера:8090`.

Обновление: после нового коммита дождитесь Actions, затем на вкладке Docker → *Check for updates* / *Force update*.

Если Unraid пишет «pull access denied» — откройте Packages в профиле GitHub → `kidlearnpayouts` →
*Package settings* → *Change visibility* → **Public**.

### Docker Compose
Для плагина «Docker Compose Manager» (или любого `docker compose`) используйте `docker-compose.yml` из репозитория: замените `ADMIN_PASSWORD` и при необходимости порт и путь к данным.

### Без GitHub Actions (сборка прямо на сервере)
```
docker build -t kidlearnpayouts:latest https://github.com/RGCustom/KidLearnPayouts.git#main
```
и в шаблоне замените Repository на `kidlearnpayouts:latest`.

## Настройки (переменные окружения)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `ADMIN_PASSWORD` | — | Пароль для записей, выплат, удаления и тарифов. Без него приложение только на просмотр |
| `TZ` | `Europe/Moscow` | Часовой пояс: влияет на «сегодня» и пятницу выплат |
| `PORT` | `8080` | Порт внутри контейнера (наружу в шаблоне — 8090) |
| `CONFIG_DIR` | `/config` | Папка с данными |
| `PUID` / `PGID` | `99` / `100` | Владелец файлов (как `nobody:users` в Unraid) |
| `SESSION_HOURS` | `12` | Сколько держится вход по паролю |
| `COOKIE_SECURE` | `0` | `1` — если заходите через HTTPS |
| `TRUST_PROXY` | `0` | `1` — если перед контейнером стоит reverse proxy (NPM, Caddy, Traefik) |

## Категории и тарифы
На странице **Тарифы** (после входа по паролю) можно добавлять, переименовывать, менять сумму и удалять категории дел
(мусор, посудомойка, прогулка с собакой — что угодно), включая штрафные (отрицательная сумма).
Галочка «раз в день» блокирует повторную запись за ту же дату. Переименование обновляет и старые записи в истории,
удаление категории не стирает уже внесённые записи (в статистике они остаются как «… (удалена)»).
Новые суммы действуют только для будущих записей — уже внесённое не пересчитывается.

## Договор
Страница **Договор** формируется из тарифов и блока «Данные договора» на странице «Тарифы» (правится после входа по паролю):
номер, город, даты, ФИО ребёнка, возраст, класс, родители (один или два, с ролью и полом для правильных окончаний).
Для PDF: «Печать / PDF» → «Сохранить как PDF».

## Данные
`/mnt/user/appdata/kidlearnpayouts/`:
- `uchet.db` — записи и выплаты (SQLite; бэкап = копия файла, лучше при остановленном контейнере);
- `tariffs.json` — категории дел, тарифы оценок, имя ученика и данные договора (правятся на странице «Тарифы»; старый формат файла преобразуется сам);
- `secret.key` — ключ сессий.

## Безопасность
- После 5 неверных паролей вход блокируется на 5 минут; смена `ADMIN_PASSWORD` разлогинивает все сессии.
- Изменяющие действия защищены CSRF-токеном, выплата дополнительно сверяет актуальную сумму.
- Заданы заголовки безопасности (CSP, `X-Frame-Options`, `nosniff`), страницы не кэшируются.
- Без HTTPS в интернет не открывайте: reverse proxy (`TRUST_PROXY=1`, `COOKIE_SECURE=1`) или VPN.

## Служебное
- `/healthz` — проверка живости (используется `HEALTHCHECK` в Dockerfile).
- Текущая версия показана в подвале страниц.
